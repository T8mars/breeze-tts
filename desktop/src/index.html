兼容策略

兼容 Transformers 4.57.x 与 5.x；独立环境不会覆盖 ComfyUI 的 Torch、Transformers、Tokenizers 或 NumPy。

Windows 任务管理器默认常显示“3D”图表；判断推理负载请切换到 CUDA / Compute 图表，或以这里的“实际推理设备”为准。CPU 仍会参与逐 token 调度、文本处理和 WAV 写入。

能力边界
